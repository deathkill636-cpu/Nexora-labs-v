# Nexora Labs — site officiel

Site vitrine statique, responsive et en français.

## Aperçu local
Ouvrir `index.html` dans un navigateur. Aucun processus de compilation n'est nécessaire.

## Déploiement sur GitHub et Vercel
1. Créer un dépôt GitHub nommé `nexora-labs-website`.
2. Ajouter tous les fichiers de ce dossier à la racine du dépôt.
3. Dans Vercel, choisir **Add New → Project**, puis importer le dépôt GitHub.
4. Framework Preset : **Other**. Build Command : laisser vide. Output Directory : `.`.
5. Déployer. Vercel fournira une URL publique.

Chaque mise à jour poussée sur la branche connectée pourra déclencher un nouveau déploiement.

## À personnaliser avant publication
- Vérifier que `contact@nexoralabs.com` est une adresse active, ou la remplacer dans `index.html`.
- Ajouter les coordonnées officielles, les liens sociaux et les projets réellement lancés.
- Configurer un domaine personnalisé dans Vercel si disponible.

## Technologies
HTML5, CSS3 et JavaScript natif. Aucune dépendance de build.
